# What's next?

You have run your first experiment with OpenDC. What's next?

- Learn what you can configure in the [documentation](/learn/category/documentation).
- Follow one of the tutorials in the [opendc-demos](https://github.com/atlarge-research/opendc-demos) repository.
- Read about [existing work using OpenDC](/research/publications).
- Get involved in the [OpenDC community](/community/support).
- Contribute to OpenDC. See [Developing with IntelliJ](./2-start-using-intellij.md) to set up the project, and read the
  [contributing guidelines](https://github.com/atlarge-research/opendc/blob/master/CONTRIBUTING.md).
