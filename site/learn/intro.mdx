# Introduction

OpenDC is a free and open-source platform for cloud datacenter simulation aimed at both research and education.

Users can construct new datacenter designs and define portfolios of scenarios (experiments) to explore how their designs
perform under different workloads, schedulers, and phenomena (e.g., failures or performance interference).

OpenDC is accessible both as a ready-to-use platform hosted by us online at [app.opendc.org](https://app.opendc.org), and as
source code that users can run locally on their own machine or via Docker.

To learn more about OpenDC, have a look through our paper on [OpenDC 2.0](https://atlarge-research.com/pdfs/ccgrid21-opendc-paper.pdf)
or on our [vision](https://atlarge-research.com/pdfs/opendc-vision17ispdc_cr.pdf). For a more recent work utilizing OpenDC, see [OpenDC-STEAM](https://atlarge-research.com/pdfs/2026-ccgrid-steam.pdf). 

The [opendc-demos](https://github.com/atlarge-research/opendc-demos) repository provides tutorials for OpenDC.

## OpenDC versions

This documentation describes OpenDC3, the main version of OpenDC that is in active development.
The latest version of OpenDC3 can be found on the `master` branch of the
[OpenDC repository](https://github.com/atlarge-research/opendc).

OpenDC2 is no longer being developed, but is still maintained at [OpenDC2 github](https://github.com/atlarge-research/opendc/tree/OpenDC2-maintenance).
The documentation of OpenDC2 is provided in the [OpenDC2 Documentation](/learn/category/opendc-2-documentation) section.
OpenDC3 can still be used to run most of the experiment files with `opendc --legacy run`. 
The [Migrating to OpenDC3](./opendc-2/migrating-to-opendc-3.md) page provides a guide on converting an OpenDC2 experiment to OpenDC3.
